# Смета PRO — версия для ПК (Windows)

Та же программа, что и мобильная **Смета PRO**
([репозиторий телефонной версии](https://github.com/alenjk93-del/Smeta-PRO)),
но для компьютера с Windows 10/11: сметы, прайс-листы, шаблоны смет,
каталог работ с базой «62 тендер». Интерфейс и данные устроены одинаково,
обмен с телефоном — файлами `.smetabook` / `.smetaest` / `.smetatpl`.

## Установка

1. Скачайте установщик `SmetaPRO-PC-Setup-vX.Y.Z.exe` со страницы
   [Releases](https://github.com/alenjk93-del/Smeta_PRO/releases).
2. Запустите его. Права администратора не нужны, ярлыки появятся на
   рабочем столе и в меню «Пуск».
3. При первом запуске Windows может показать синее окно SmartScreen
   (у файла нет цифровой подписи): нажмите «Подробнее» →
   «Выполнить в любом случае».

Файлы `.smetabook`, `.smetaest` и `.smetatpl` после установки открываются
двойным щелчком сразу в программе. Данные хранятся в профиле пользователя
(`%APPDATA%\Смета PRO`) и не удаляются при удалении программы.

## Обновления

Программа сама проверяет обновления в релизах этого репозитория —
при запуске и по нажатию на номер версии, как на телефоне. Найдя новую
версию, предлагает скачать и установить поверх; данные сохраняются.

## Для разработчиков

- Веб-часть (`app/index.html`, `app/db.js`) — та же, что в мобильной
  версии, берётся из репозитория Smeta-PRO без изменений.
- Оболочка — Electron (Windows), мост к настольным функциям —
  `preload.js`; установщик — NSIS (`installer.nsi`).
- Полное описание устройства и пересборки — в `README-PC.md`.
- Правила репозитория: никаких прямых коммитов в `main` — только ветка
  и Pull Request, слияние делает владелец вручную.
